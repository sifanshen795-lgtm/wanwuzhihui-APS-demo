1. 文档说明

1.1 文档目的

本文档用于描述金旸改性塑料 MES Demo 系统的功能需求，作为后续原型设计、Demo 开发、业务演示和需求评审的依据。

系统围绕改性塑料生产过程中的三段式生产模式进行设计：配色 → 配料 → 挤出。

1.2 Demo 范围

  • 基础数据维护
  • 销售订单同步与 MRP 运算
  • 生产订单与用料清单生成
  • 计划排程与排程下推
  • 批次工单与配方单生成
  • APP 现场投料、包装、物料转移
  • 生产过程记录
  • 条码档案与即时库存
  • 基准料储罐管理

1.3 暂不考虑范围

  • 用户管理
  • 角色权限
  • 菜单权限
  • 审批流配置
  • 多组织、多工厂、多账套
  • 复杂质量管理
  • 财务成本核算
  • 正式接口异常重试机制
  • 复杂设备联网协议

2. 业务背景

金旸改性塑料生产主要包含原料、中间物料、主产品/产成品三类生产对象。

类型说明
原料外购材料，通常来自 ERP 库存，不需要 MES 工单生产。
中间物料由配色、配料阶段生产得到，如色包、料包等。
主产品/产成品通过挤出阶段生产得到的最终产品。

系统需要支持以下生产特点：

  • 中间物料需要先生产，再投入主产品生产。
  • 主产品生产需要根据产线单锅产量拆分批次。
  • 排程需要考虑产线、停机时间、清机时长和颜色深浅。
  • 现场执行依赖扫码和称重。
  • 基准料存在袋装转储罐场景。

3. 系统总体流程

3.1 主业务流程

销售订单 → MRP 运算 → 生成生产订单 → 生成用料清单 → 计划排程 → 排程下推 → 生成主产品批次工单 → 生成中间物料批次工单 → 生成配方单 → 配方单审核 → APP 现场执行 → 扫码投料 → 包装称重 → 打印条码 → 生成生产记录 → 更新条码档案 / 即时库存

3.2 三段式生产流程

阶段流程产出
配色配色批次工单 → 扫码投料 → 包装称重 → 打印色包条码色包类中间物料
配料配料批次工单 → 扫码投料 → 包装称重 → 打印料包条码料包类中间物料
挤出主产品批次工单 → 投原料/中间物料/基准料 → 参数采集 → 包装打码产成品

5.4.3 计划排程

计划排程用于将生产订单安排到具体产线和时间，并生成可下推的排程结果。

排程规则说明
相同产品优先生产相同主产品连续排产
同类产品优先生产同一产品组优先连续排产
由浅至深生产根据色级顺序从浅到深排产
交期紧急程度生产交期越早，优先级越高
订单创建时间先后生产创建时间越早，优先级越高
物料已齐套订单优先生产齐套订单优先
大订单优先生产数量较大的订单优先

工时计算：锅数 = 生产订单数量 / 产线单锅产量，向上取整；订单标准工作时长 = 锅数 × 工艺单锅标准工作时长。

业务规则：自动排程时根据产线与产品关系匹配可生产产线，避开生产日历中配置的停机时间，任务之间如存在物料切换应显示清机时长；自动排程后支持拖拽调整产线。Demo 阶段重点展示排程结果，不要求实现复杂高级优化算法。

5.4.4 排程输出

排程输出用于将计划排程结果下推为后续可执行单据。排程下推后，排程在甘特图内锁定；已锁定排程不可再拖拽调整；下推后进入批次工单生成逻辑。

5.4.5 批次工单

批次工单是现场执行的任务单元。系统根据主产品生产订单、产线单锅产量和主产品与中间物料关系表，自动生成主产品批次工单和中间物料批次工单。

工单类型说明
主产品批次工单挤出阶段执行，用于生产最终产成品。
中间物料批次工单配色、配料阶段执行，用于生产色包、料包等中间物料。

主产品批次数量 = 生产订单数量 / 产线单锅产量，向上取整。中间物料需求量根据主产品批次工单数量和主产品与中间物料配比计算。

生产物料工单生产对象
计划数量批次计划数量
产线计划产线

工单状态待配方 / 待审核 / 待执行 / 执行中 / 已完成

投料功能分为中间物料批次工单投料和主产品批次工单投料。

场景操作方式关键规则
中间物料批次工单投料扫描物料条码，自动带出条码号、物料信息、批号、剩余量；记录投料量和投料后剩余量。若配方单指定批号，实际扫描批号必须一致；可对接电子秤获取投料前、投料后重量；尾料无剩余价值时可将剩余量记 0 并生成损耗单。
主产品批次工单投原料/中间物料先扫投料口码，再扫物料条码。若配方单指定投料口，实际投料口必须一致；若指定批号，实际批号必须一致；投料后更新条码剩余量。
主产品批次工单投基准料扫描储罐，记录工单生产前和生产后储罐数量。基准料实际投料量 = 生产前储罐数量 - 生产后储罐数量；投料后扣减储罐库存。

6.1.1.3 包装

包装类型主要功能业务规则
中间物料包装对接电子秤获取每包中间物料数量；打印色包、料包条码。每打印一个条码生成一条中间物料条码档案和生产包装记录，并增加中间物料库存。
主产品包装对接电子秤获取每包主产品数量；打印主产品条码。每打印一个条码生成一条成品条码档案和生产包装记录，并增加成品库存。

6.1.2 物料转移

用于将袋装基准料转移至虚拟储罐。

功能说明
扫描袋装基准料条码自动带出物料、批号、当前剩余量。
选择或扫描目标储罐选择转入的虚拟储罐。
输入转移数量系统计算转移后条码剩余量和储罐数量。
更新库存来源条码剩余量减少，目标储罐当前数量增加。
生成物料转移记录记录来源条码、目标储罐、转移数量和时间。

7. 核心业务规则汇总

类别规则
销售订单与 MRP只有未 MRP 的销售订单可以参与 MRP 运算；多个销售订单可合并生成一个生产订单；MRP 后销售订单状态变为已 MRP；原料参与齐套判断，中间物料不参与齐套判断。
生产订单与用料清单MRP 后自动生成生产订单；一个生产订单可关联多个销售订单；生产订单自动匹配物料清单；用料清单支持修改并参与配方单生成。
排程自动匹配可用产线，避开停机时间，显示清机时长；按锅数和工艺单锅标准工作时长计算工时；下推后甘特图锁定。
批次工单主产品批次工单按产线单锅产量拆分；中间物料批次工单根据主产品批次工单和主产品与中间物料关系自动生成。
配方单根据用料清单和批次工单生成；支持修改比例、指定批次、指定投料口；审核通过后 APP 才允许执行。
投料扫码自动带出条码号、批号、剩余量；校验指定批号和指定投料口；投料后更新条码剩余量；尾料无价值可生成损耗单。
包装与条码包装称重后打印中间物料或成品条码；生成包装记录、条码档案并更新库存。
储罐与基准料袋装基准料可转储罐；储罐基准料可供多个工单投料；投料量按生产前后储罐数量差值计算。

14. Demo 设计重点总结

亮点说明
三段式生产闭环配色生产中间物料，配料生产中间物料，挤出消耗原料 + 中间物料 + 基准料，最终产出成品。
主产品与中间物料联动主产品批次工单生成后，系统自动生成配色、配料中间物料批次工单。
单锅拆分生产订单不是现场最小执行单位，系统根据产线单锅产量拆成多个批次工单。
扫码防错投料口校验、批号校验、条码剩余量校验。
条码追溯原料条码 → 中间物料条码 → 成品条码。
基准料储罐袋装基准料转储罐，储罐基准料供多个工单投料，按生产前后储罐数量计算消耗。
